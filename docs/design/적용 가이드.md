# Leadpot 리디자인 적용 가이드 (Claude Code용)

이 문서는 시안(`전체 화면 리디자인.dc.html`, 3a~3h)을 실제 코드베이스에 적용하기 위한 지시서다.
Claude Code에 이 문서를 그대로 주고 "이 가이드대로 적용해줘"라고 하면 된다. 시안 HTML 파일도 함께 주면 정확도가 올라간다.

## 0. 원칙

- **색은 그대로**: 기존 `styles/tokens.css`의 인디고/그린/중립 팔레트를 유지한다. 색 토큰 값은 바꾸지 않는다 → 다크모드 자동 대응 유지.
- **형태만 교체**: 라운드를 키우고(카드 18px, 컨트롤은 pill 999px), 버튼·입력·필터를 pill로 통일한다.
- **구조 변경은 인박스 1곳**: 통합 인박스를 3-pane(rail)에서 **스플릿 뷰(목록 430px + 상세 상시 표시)**로 바꾼다. 나머지 화면은 스타일만 바꾼다.
- 기존 CSS 레이어 구조(tokens → base → components → layout → features)를 그대로 쓴다. 새 파일을 만들지 말고 기존 파일을 수정한다.

## 1. 토큰 (styles/tokens.css)

```css
/* 변경 */
--radius: 18px;        /* 카드 (기존 14px) */
--radius-sm: 12px;     /* 작은 요소 (기존 9px) */
/* 추가 */
--radius-pill: 999px;  /* 버튼·입력·칩·세그먼트 공통 */
```

색·타이포·밀도 토큰은 변경 없음.

## 2. 공통 컴포넌트 (base.css / components.css)

| 요소 | 변경 |
|---|---|
| `.btn` | `border-radius: var(--radius-pill)`. primary=인디고 채움(유지), "유효 확정" 등 성과 액션만 그린 |
| `.input`, `select.input` | `border-radius: var(--radius-pill)`, `padding: 9px 16px`, 배경 `var(--surface)` (textarea만 `--radius-sm`) |
| `.pill`, `.badge`, 상태 pill `.ld-*` | 유지 (이미 pill) — 폰트 11.5~12px, `font-weight: 700` |
| `.type-seg` (세그먼트) | 유지하되 활성 탭 = `var(--surface)` 배경 + 인디고 글자 + 얕은 그림자 |
| `.card` | `border-radius: var(--radius)` — 토큰 변경으로 자동 반영 |
| 테이블 행 액션 버튼 | `.btn-sm`을 pill로: `border-radius: var(--radius-pill); padding: 5px 13px` |
| 시맨틱 색 규칙 유지 | 신규=인디고 · 유효/전환=그린 · AS=앰버 · 무효=로즈 · 커스텀=중립 (V29/U7 그대로) |

## 3. LNB (layout.css + TopBar.tsx)

- 색·구조 유지(잉크 패널 `--lnb-*`). 변경점:
  - `.lnb-link { border-radius: 12px; }`
  - **섹션 제목 확대**: `.lnb-section-toggle`을 `font-size: 12.5px; font-weight: 800; letter-spacing: 0.14em; color: #aab1dd(라이트)/기존 --lnb-group보다 한 단계 밝게`, 제목 오른쪽에 1px 라인(`background: var(--lnb-active-bg)`)을 flex로 채움 → 시안 참고. 다크모드는 `--lnb-group`을 밝게 조정.
  - 하위 항목 설명(`.lnb-link-desc`)은 제거해도 됨(시안은 라벨만) — 유지 원하면 그대로.
  - 활성 항목에 카운트 뱃지(리드 미확인 수) 추가: 인디고 채움 pill.

## 4. 통합 인박스 → 스플릿 뷰 (LeadInboxPage.tsx + features/leads.css) ★ 핵심

시안 3b. 3-pane rail 구조를 다음으로 교체:

```
.app-shell (가로)
 ├ LNB 224px
 ├ 목록 칼럼 430px (flex:none, border-right)
 │   ├ 제목 "리드" + 검색(pill) + 셀렉트 3개(상태/폼/기간, pill)
 │   ├ 세그먼트: 전체 N / 오늘 N / 미확인 N
 │   ├ 리드 카드 리스트 (2줄: 이름+상태pill+시각 / 연락처+요약 말줄임)
 │   │   선택 행: `--indigo-soft` 배경 + inset 1.5px 인디고 링, radius 14px
 │   └ 하단 페이징 (1–25 / 128, ← →)
 └ 상세 pane (flex:1, 항상 표시)
     ├ 헤더: 폼명·#id 캡션 / 이름 h2 / 연락처·접수일시 / [폼에서 열기][유효로 확정(그린)]
     └ 2단 그리드: (답변, 방문자) | (상태 칩, 태그, 메모·이력)
```

- 기존 rail 필터(보기/기간/상태/출처)는 목록 칼럼 상단의 **셀렉트 3개 + 세그먼트**로 이동. 카운트는 세그먼트와 셀렉트 옵션에 표기.
- `LeadSidePanel`의 `variant="pane"`을 이 상세 pane으로 재사용(내용 배치만 2단으로). 첫 진입 시 첫 리드 자동 선택 — 오른쪽이 비지 않게.
- 리드가 0건이면 상세 pane에 빈 상태 안내.
- 일괄작업: 목록 카드에 hover 시 체크박스 노출(또는 "선택" 모드 토글) — 기존 벌크 API 유지.
- ≤900px: 목록만 표시, 행 탭 → 상세가 전체 화면으로 (기존 drawer 로직 재사용).
- 폼별 리드 목록(`/forms/:id/leads`)은 구조 유지 + 스타일만(행 radius, pill).

## 5. 대시보드 (DashboardPage.tsx) — 시안 3a

- KPI 4카드 유지. hover 시 `border-color: var(--indigo)`.
- **추가(제안)**: "오늘 들어온 리드" 카드 — 인박스 API(`getInbox({from:today,to:today,size:4})`) 재사용, 4행 미리보기 + "인박스에서 모두 보기 →". 서브도메인 카드는 오른쪽 1열로.

## 6. 리드폼 목록 등 테이블 화면 — 시안 3c

- 대상: 리드폼·랜딩·요소·동의문서·IP차단·광고주 목록.
- `card card-table` 라운드는 토큰으로 자동. 유형 등 분류는 pill(기본형=인디고soft, 스텝형=그린soft). 행 액션은 pill 버튼(삭제는 rose-ink + hover rose-soft).

## 7. 리드폼 편집기 (FormEditPage.tsx) — 시안 3d

- 헤더: ← 목록 / 폼 이름 / 유형 pill / [미리보기][저장(인디고 pill)].
- 좌: 기본 정보 · 항목(블록 행: ⠿ 핸들 + 라벨 + 유형 pill + 필수 + 편집/삭제, radius 14px, hover 인디고 테두리) · "+ 입력 항목" 등 점선 pill 버튼 · 동의/알림 카드(발송 가능 상태 안내는 그린soft 박스).
- 우: `position: sticky` 모바일 미리보기(기존 DevicePreviewFrame) 340px.

## 8. 통계 (StatsPage.tsx + features/stats.css) — 시안 3e

- 필터바: 기간 세그먼트 + 대상 셀렉트를 헤더 오른쪽으로 (카드 아님).
- KPI 4 → 추이 차트(막대 radius 6px, 트래픽=`--indigo-soft`보다 진한 #c3c8ea급 연인디고, 리드=그린) → 퍼널(가로 pill 게이지) + UTM 등 바 카드(가로 pill 게이지, 인디고 투명도 단계).

## 9. 광고주 포털 (AdvertiserLeadsPage.tsx 등) — 시안 3f

- 상단 바 유지, 탭을 pill로(활성=인디고soft).
- 인사 헤더에 할 일 문구("새 리드 N건이 기다려요") + KPI 3카드(미확인/오늘 접수/이번 달 전환).
- 리드 행: 이름(미확인 점) · 요약 · **전화 버튼(그린soft pill, 📞 번호)** · 상태 셀렉트(상태색 pill — 기존 `.st-*` 변수 연결 유지) · 시각.

## 10. 로그인 (auth.css) — 시안 3g

- 카드 radius 22px, 워드마크 상단 배치, 입력 pill, 로그인 버튼 인디고 pill 풀폭.

## 11. 공개 폼 (formRenderers + public.css) — 시안 3h

- 입력 radius 14px(모바일에서 pill은 과함), 제출 버튼 radius 16px 풀폭 — **버튼/강조색은 리드폼별 styleConfig 유지**.
- 동의 영역: surface-2 라운드 박스 + "전체 동의" 상단 배치.

## 12. 다크모드

- 색 토큰을 바꾸지 않았으므로 기존 `data-theme` / `prefers-color-scheme` 오버라이드가 그대로 동작.
- 새로 추가한 하드코딩 색이 없는지 확인 — 반드시 `var(--*)` 토큰으로 쓸 것 (시안의 hex는 라이트 토큰 값이다: #3a43c0=--indigo, #eef0f9=--surface-2 등).

## 13. 적용 순서 (커밋 단위 제안)

1. tokens.css radius 변경 + `--radius-pill` 추가 → 전역 라운드 확인
2. base/components (버튼·입력·pill·세그먼트) → 전 화면 회귀 확인
3. LNB (섹션 제목 확대 포함)
4. 인박스 스플릿 뷰 (가장 큰 작업 — 별도 커밋)
5. 대시보드 / 목록 화면들 / 편집기 / 통계
6. 광고주 포털 / 로그인 / 공개 폼
7. 375px·1280px·1680px 3개 폭 + 다크모드 검증

각 단계 후 `tsc -b` + prod 빌드, U3 방식의 DOM 실측(행 높이·열 정렬·대비 ≥4.5:1) 권장.
