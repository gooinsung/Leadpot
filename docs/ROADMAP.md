## 프로젝트 = Leadpot (리드팟)

디비카트 벤치마킹 — 랜딩페이지로 리드(DB)를 수집·관리하는 서비스. 차별점: **폼 독립·재사용 + 폼 유형(기본형/스텝형) 확장 구조 + 폼 내 콘텐츠 블록**.

## 1차 확정 범위 (34개)

| 영역 | 선택된 기능 |
|---|---|
| 계정 | A1 로그인, A2 다계정, A4 비번재설정 |
| 랜딩 제작 | B1 단순랜딩, B2 폼항목/동의, B3 이미지 상하배치, B5 요소 자동배치, B7 미리보기 |
| 폼 관리 | C1 디자인 커스터마이징, C2 완료페이지/리다이렉트 |
| 공개·수집 | D1 공개URL+수집, D2 커스텀 도메인 🔒 |
| 리드 관리 | E1 목록/상태, E2 CSV, E3 중복관리, E4 휴지통 |
| 알림 | H3 카카오 알림톡 🔒 |
| 마케팅 | I1 픽셀, I3 SEO, I4 전환분석, I5 요소 노출/클릭 |
| 통계 | J 방문자 정보(IP·OS·기기 PC/모바일·유입경로) 수집·통계 |
| 보안·차단 | K1 SSL, K2 IP차단, K3 중복제출방지, K5 접근권한 |
| 우리 개선 | M1 폼독립·재사용, M2 기본형폼, M3 스텝폼, M4 콘텐츠블록, M5 본인인증🔒, M6 외부임베드, M7 유형확장구조 |

🔒 외부 준비물 필요: **D2**(도메인 구매·DNS), **H3**(사업자등록+카카오 비즈메시지), **M5**(SMS/PASS 본인인증 업체).

각 Phase는 끝에 "검증" 통과 후 다음으로. 진행상태: ⬜ 예정 / 🔄 진행중 / ✅ 완료

|---|---|---|:---:|
| **0** | 셋업 & 배포 파이프라인 | 로컬 스켈레톤·/api/health·CORS 검증 ✅ / 클라우드 배포는 계정 준비 후 | 🔄 (로컬 완료) |
| **1** | 인증 & 계정 | A1, A2, A4, K5, K1 | ⬜ ← **다음** |
| **2** | 폼 빌더 ★핵심 | M1, M2, M7, B2, M4, C1, M3, C2, M6, M5(옵션자리) | ⬜ |
| **3** | 랜딩 빌더 & 폼 연결 | B1, B3, B5, B7 | ⬜ |
| **4** | 공개 페이지 & 수집 | D1, J(방문자정보), D2 | ⬜ |
| **5** | 리드 관리 & 통계 | E1~E4, J, K2, K3 | ⬜ |
| **6** | 마케팅·트래킹 | I1, I3, I4, I5 | ⬜ |
| **7** | 알림 🔒 | H3 (준비물 필요, 없으면 후순위) | ⬜ |

### Phase별 검증 기준
- **0**: 배포된 React 화면에서 `api.도메인/api/health` 호출 성공(CORS 포함)
- **1**: 가입→로그인→내 데이터만 보이는 대시보드 진입
- **2**: 기본형·스텝형 폼 생성→미리보기 동작
- **3**: 랜딩 생성→폼 연결→미리보기
- **4**: 공개 링크→폼 제출→리드+방문자정보(IP/OS/기기) 저장
- **5**: 리드 목록/상태/CSV/휴지통/중복·IP차단/통계 동작
- **6**: 픽셀 삽입·전환/클릭 데이터 확인
- **7**: 신규 리드 카카오 알림톡 발송
