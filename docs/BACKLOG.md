## 📋 전체 기능 (여기서 고르기)

### A. 계정 · 인증
- [ ] **A1. 이메일 회원가입/로그인** ⭐ — 이메일·비번으로 가입하고 로그인하는 기본 기능
- [ ] **A2. 다계정·멀티 랜딩** ⭐ — 한 계정으로 랜딩페이지 여러 개 만들고 관리
- [ ] **A3. SNS 로그인** — 네이버·카카오·페북 버튼으로 간편 로그인
- [ ] **A4. 비밀번호 재설정** — 비번 잊었을 때 이메일로 재설정 링크 보내기

### B. 랜딩페이지 제작
- [ ] **B1. 단순형 랜딩 생성** ⭐ — 이미지 몇 장 + 폼 얹어서 코딩 없이 페이지 만들기
- [ ] **B2. 폼 항목 구성 / 개인정보 동의** ⭐ — 이름·연락처 등 입력칸 추가, 필수여부, 동의 체크박스
- [ ] **B3. 이미지 상/하 배치** — 폼 위·아래로 이미지 여러 장 순서대로 넣기
- [ ] **B4. 블록 빌더(고도화)** — 드래그로 요소 추가·이동, 색상·크기 편집 (가장 손 많이 감)
- [ ] **B5. 요소 자동 배치** — 이미지·폼·버튼을 알아서 예쁘게 정렬
- [ ] **B6. 업종별 템플릿** — 금융·병원·교육 등 완성형에서 시작
- [ ] **B7. 실시간 미리보기(PC/모바일)** — 만들면서 바로 화면 확인, 모바일 뷰 전환

### C. 폼 관리
- [ ] **C1. 폼 디자인 커스터마이징** — 폼 가로 크기·색상·글자 크기 바꾸기
- [ ] **C2. 제출 완료 화면/리다이렉트** — 신청 끝나면 감사 페이지 보여주거나 다른 링크로 이동

### D. 공개 페이지 · DB 수집
- [ ] **D1. 공개 URL + 폼 수집** ⭐ — 만든 페이지를 링크로 배포, 방문자가 남긴 정보를 DB에 저장 (서비스 핵심)
- [ ] **D2. 커스텀 도메인 연결** 🔒 — 내 도메인(mysite.com)으로 페이지 열기
- [ ] **D3. 사용자별 서브도메인** (나중에) — 서비스 도메인이 `lead-pot.com`이면 사용자마다 `bali.lead-pot.com`, `test.lead-pot.com` 식 서브도메인 할당. 그 사용자의 랜딩은 `bali.lead-pot.com/landing/{landingId}` 형태로 접근. (와일드카드 DNS/SSL + 서브도메인→계정 라우팅 필요, D2와 연계)

### E. DB / 리드 관리 (디비내역)
- [ ] **E1. 리드 목록/상세 + 상태관리** ⭐ — 수집된 고객 정보 보기, 신규/상담중/완료 표시
- [ ] **E2. CSV/엑셀 내보내기** ⭐ — 모은 DB를 엑셀 파일로 다운로드
- [ ] **E3. 중복 데이터 관리** — 같은 사람이 여러 번 넣은 것 걸러내기
- [ ] **E4. 휴지통(복구)** — 실수로 지운 데이터 되살리기
- [ ] **E5. 구글 스프레드시트 전송** — 수집 DB를 구글 시트로 자동 보내기

### F. CRM (팀플 / Team+)
- [ ] **F1. 팀원 관리** — 팀장·담당자 등록하고 조직 구성
- [ ] **F2. DB 자동 배정** — 새 DB가 들어오면 팀원에게 설정한 수량대로 자동 분배
- [ ] **F3. 진행 상태 관리** — 상담 단계(접수→통화→완료 등) 내 맘대로 설정
- [ ] **F4. 고객 관리(메모)** — 고객별 상담 메모·이력 남기기
- [ ] **F5. 개별/다수 SMS 발송** 🔒 — 고객 골라서 문자 보내기
- [ ] **F6. 팀 통계** — 일별/월별/팀원별/단계별 실적 보기
- [ ] **F7. 외부 랜딩 API 연동** — 다른 데서 만든 랜딩의 DB도 여기로 모으기
- [ ] **F8. 휴지통 복구(고객)** — 지운 고객 정보 복구

### G. 파티 (데이터 공유)
- [ ] **G1. 계정 간 데이터 공유** — 다른 계정과 DB만 공유해서 협업

### H. 알림
- [ ] **H1. 이메일 알림** — 새 DB 들어오면 내 메일로 알려주기
- [ ] **H2. SMS 문자 알림** 🔒 — 새 DB 들어오면 문자로 알려주기
- [ ] **H3. 카카오 알림톡** 🔒 — 카톡으로 알림 (사업자 등록 필요)
- [ ] **H4. 앱/웹 푸시 알림** — 브라우저·폰 푸시로 알림

### I. 마케팅 · 트래킹
- [ ] **I1. 광고 픽셀 설치** — 구글·메타·틱톡·당근 광고 추적 코드 심기
- [ ] **I2. UTM 추적** — 어느 광고·경로로 들어왔는지 기록
- [ ] **I3. 검색엔진 등록(SEO)** — 구글·네이버 검색에 잘 노출되게 메타태그 세팅
- [ ] **I4. 전환 분석** — 방문 → 신청까지 얼마나 전환되는지 퍼널 분석
- [ ] **I5. 요소 노출/클릭 분석** — 어떤 이미지·버튼이 많이 눌렸는지 보기

### J. 통계 · 분석
- [ ] **J1. 접속 통계** — 방문자 수, 기간별 추이
- [ ] **J2. 유입 경로** — 어디서(리퍼러)·어떤 기기로 왔는지
- [ ] **J3. UTM 캠페인 통계** — 캠페인별 성과 비교
- [ ] **J4. 전환율 대시보드** — 방문 대비 신청률 한눈에

### K. 보안 · 차단
- [ ] **K1. SSL 암호화** ⭐ — https 적용 (Cloudflare로 무료, 사실상 기본 포함)
- [x] **K2. IP 차단** — 리드폼별 IP/CIDR 대역 차단(사유 메모) + 차단 접속 로그 확인. 차단 시 공개 제출 거부(중립 메시지), 시도는 로그로 기록(REQUIRES_NEW 로 롤백과 무관하게 저장). Flyway V13(ip_blocks·ip_block_hits), `com.leadpot.ipblock`, 관리 UI `/forms/{id}/ip-blocks`.
- [ ] **K3. 중복 제출 방지** — 짧은 시간 반복 제출·스팸 막기
- [ ] **K4. 봇/에이전트 차단** — 자동 프로그램(봇) 제출 걸러내기
- [ ] **K5. 리드 데이터 접근 권한 통제** ⭐ — 내 DB는 나(내 팀)만 보게 하기

### L. 결제 · 요금제
- [ ] **L1. 요금제/이용권** 🔒 — 유료 플랜 만들고 랜딩별 결제
- [ ] **L2. PG 결제 연동** 🔒 — PortOne·토스로 실제 결제 받기
- [ ] **L3. 정기결제(구독)** 🔒 — 매월 자동 결제
- [ ] **L4. 메시지 크레딧** — 문자 발송용 크레딧 충전/차감

### M. 우리만의 개선 기능 (디비카트에 없거나 다르게)
- [ ] **M1. 폼 독립·재사용** ⭐ — 입력폼을 랜딩과 별도로 만들고, 하나의 폼을 여러 랜딩에서 재사용
- [ ] **M2. 기본형 입력폼(BASIC)** ⭐ — 한 화면에 항목 나열하는 일반 폼
- [ ] **M3. 선택형/스텝형 입력폼(STEP)** — 배경 블러 + 단계별 선택(질문 N/총) → 연락처 → 제출 (은오 자가진단 스타일)
- [ ] **M4. 폼 내 콘텐츠 블록 삽입** — 입력 항목 사이에 이미지·HTML·텍스트·구분선을 자유롭게 배치
- [ ] **M5. 휴대폰 본인인증 옵션** 🔒 — 폼에서 본인인증을 선택적으로 ON/OFF (외부 인증 서비스)
- [ ] **M6. 폼 외부 임베드** — 만든 폼을 외부 사이트/블로그에 삽입
- [ ] **M7. 확장 가능한 폼 유형 구조** — 새 폼 유형(팝업/챗형 등)을 렌더러 추가만으로 확장
- [ ] **M8. 재사용 HTML 요소 라이브러리 (요소 생성기)** — 미리 만든 HTML 요소(플로팅 헤더·고정 헤더·푸터·CTA·신청현황 등)를 저장해두고, 랜딩(및 폼)의 HTML 블록에서 꺼내 삽입해 재사용
  - 관리: `html_components`(owner_id·name·category·html·config) + 전용 관리 페이지(생성/편집/목록), 동의문서 관리와 유사 패턴
  - 삽입: 랜딩/폼 편집기에 "저장된 요소 불러오기"(셀렉트) → 해당 위치에 삽입
  - 요소 유형: **정적**(헤더/푸터/CTA/텍스트 등) 먼저 → **동적**(신청현황=실시간 리드 수 티커, 최근 신청자, 남은 자리 등)은 런타임 데이터 필요하므로 2단계
  - 배치 옵션 고려: 일반 삽입 vs 고정/플로팅(스크롤 고정) — 요소 config로 처리
