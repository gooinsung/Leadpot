# docs/FEATURES.md — 디비카트 전체 기능 카탈로그

> 실제 서비스(dbcart.net 메인·요금제·랜딩정의 페이지, tp.dbcart.net 팀플 CRM) 분석 기반.
> 우리가 벤치마킹 대상으로 삼는 **전체 기능**을 카테고리별로 정의하고, 구현 난이도·필요 외부 서비스·우선순위를 표기한다.

## 범례

- **난이도**: 🟢 쉬움 · 🟡 보통 · 🔴 어려움
- **우선순위**: `MVP`(핵심 최소기능) · `2차`(고도화) · `후기`(고급/수익화)
- **외부 서비스**: 우리가 직접 못 만들고 외부에 의존/유료가 필요한 항목

> 결론: **모든 기능은 구현 가능**하다. 순수 소프트웨어 기능은 직접 개발하고, 문자·알림톡·결제·커스텀 도메인 정도만 외부 서비스가 필요하다.

## 우선순위 요약 (구현 순서 가이드)

```
MVP  : A(이메일/다계정) · B(단순형) · C(항목/동의) · D(공개URL/수집) · E(조회/CSV) · K(SSL/권한)
2차  : B(빌더 고도화·템플릿) · C(디자인) · E(중복/휴지통/시트) · H(SMS/이메일 알림)
       · I(픽셀/UTM/SEO/전환) · J(통계) · K(IP/봇 차단) · A(SNS로그인)
후기 : F(팀 CRM 전체) · G(파티) · H(카카오 알림톡) · L(결제/구독)
```
